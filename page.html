What stays private?

Your browsers calculate the result together using secure two-party computation. The relay forwards encrypted messages; it is not given your answers or result.

If you choose no, a completed no-match result does not tell you their answer. If you choose yes, it does. Someone can also choose yes just to learn the other answer.

The relay sees connection details, including IP addresses and timing. No names, accounts, analytics, or saved answers.

Why download?

A saved file cannot be changed by later website updates. Its JavaScript and cryptographic library are bundled inside; it fetches no new code.

Downloading does not prove the original file is trustworthy. Someone independent would need to review the code and verify the file. The connection code checks your peer, not the app’s safety.

This app and its bundled cryptographic implementation have not been independently audited for this use.

What if something goes wrong?

A disconnection or failed check is not a rejection before the deadline. Agree together before trying a new session. There is no automatic retry with your answer.

If the deadline passes without a completed result, the outcome is “No further date.” This is the agreed default, not evidence of anyone’s submitted answer.

Either participant can interrupt the exchange. Both receiving a result at exactly the same time cannot be guaranteed.
