# Async Mutual Yes at a glance

[Plan](PLAN.md)

Make the page a direct Yes/No choice with durable private progress, clear next steps, and a downloadable client.

1. [20m] Verify a resumable cryptographic protocol and durable message storage without giving the server individual answers.
2. [30m] Build the simple voting and return flow, including saved progress and acknowledgements.
3. [20m] Test separate visits, reloads, all outcomes, deadlines, and failures; deploy and verify.

The output is one private link per participant, a minimal page, a self-contained download, and explicit instructions when another visit is needed.
